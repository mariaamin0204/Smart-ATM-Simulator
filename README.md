# 🏧 Interactive 3D ATM Simulator

An interactive, responsive 3D ATM simulator built using HTML, CSS, JavaScript, and the Web Audio API to deliver a realistic banking terminal experience.

## 🚀 Live Demo
[Click Here to View Live Project](https://smart-atm-simulator.netlify.app/)
## ✨ Key Features
- 🔑 **PIN Authentication:** Realistic keypad interface with PIN validation.
- 💰 **Banking Operations:** Deposit cash, withdraw funds, and check real-time balance.
- 🔊 **Audio Feedback:** Integrated Web Audio API for authentic keypress and cash dispensing sound effects.
- 📜 **Transaction History:** Real-time log tracking all user deposits and withdrawals.
- 🎨 **3D Interactive UI:** Built using modern CSS 3D transforms, animations, and clean visual styling.
- 📱 **Fully Responsive:** Smoothly adapts across screens from mobile to desktop.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (3D Transforms & Keyframe Animations), JavaScript (ES6+)
- **Audio:** Web Audio API
- **Deployment:** Netlify / Vercel
